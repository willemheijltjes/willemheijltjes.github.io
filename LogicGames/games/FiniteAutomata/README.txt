--------

1. The contents of this zip are as follows:

- intro.html
	The html file for the introduction to the game and tutorial.
- intro.js
	The javascript file containing the logic behind the tutorial and all the
	functions needed for it to run properly.
- webpage.html
	The html file for the main game.
- canvas.js
	The javascript file containing the logic behind webpage.html and the
	various algorithms and functions needed for the game to run properly.
- myTemplate.css
	A style file, containing information used by the html pages for styling
	purposes, such as colour and size of objects. Adapted from bootstrap.
- images
	A folder containing all the images used as part of the game as well as a
	gif showing basic controls for the game.
- bootstrap.min.js
	A file from the twitter bootstrap project used to produce neat tool tips
	for the buttons in the game.
- bootstrap-ie10-viewport-bug-workaround.js
	A file from the twitter bootstrap project used to work around a bug
	which can arise when using windows 8 or surface

--------

2. Running the game

The game can be played by opening either intro.html or webpage.html. Running
the former will open an introduction to the game and a short tutorial
explaining the controls, before moving onto the main game. Running the latter
will miss out this tutorial.
The game should be compatible on recent versions of popular browsers.
